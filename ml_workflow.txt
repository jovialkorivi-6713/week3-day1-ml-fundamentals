1. Data Collection

Data collection is the first step in machine learning. It involves gathering relevant data from different sources. The quality of data directly impacts the model performance. In this project, student performance data was collected and stored in a CSV file.

2. Data Cleaning

Data cleaning is the process of removing errors, duplicates, and missing values from the dataset. Clean data helps improve model accuracy. In this dataset, there were no missing values, so minimal cleaning was required.

3. Feature Selection

Feature selection involves choosing the most relevant input variables for prediction. The selected features were Study_Hours, Attendance, and Assignments. These factors are expected to influence student marks.

4. Train-Test Split

The dataset is divided into training and testing data. The training data is used to teach the model, while testing data is used to evaluate performance. We used an 80-20 split.

5. Model Training

Model training is the process where the machine learns patterns from the training data. Linear Regression was used to establish relationships between study habits and marks.

6. Testing

After training, the model is tested using unseen data. This helps determine how well the model can predict new observations.

7. Evaluation

Evaluation measures model performance using metrics such as MAE and R² Score. These metrics indicate prediction accuracy and reliability.

8. Prediction

Prediction is the final step where the trained model estimates outcomes for new data. In this project, student marks were predicted using study hours, attendance, and assignments.
